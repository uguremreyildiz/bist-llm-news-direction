# Mapping from the paper to this repository

Every file below is regenerated by `python reproduce.py` from `data/panel_bge_m3.parquet`
alone. The reference values reported in the paper are listed below so that the output of a
fresh run can be compared directly.

| Reported in the paper | File produced by `reproduce.py` |
|---|---|
| Out-of-sample accuracy, macro-F1, ROC-AUC, binomial *p*-value, *n* = 1,152 | `outputs/reproduced_summary.json` |
| Confusion matrix of the selected model | `outputs/confusion_matrix.csv` |
| Per-ticker accuracy against the always-long rate | `outputs/per_ticker.csv` |
| Coefficient importance by feature family | `outputs/coefficient_family_shares.csv` |
| Annualised Sharpe ratios and cumulative returns of the four strategies | `outputs/sharpe.csv` |
| Weekly out-of-sample predictions underlying the backtest figure | `outputs/oos_predictions.csv` |
| Block-bootstrap confidence intervals and p-values (Section 5.1) | `revision/outputs/tables/T_A3_inference.csv`, `A3_summary.json` (run `revision/A3_inference/inference.py`) |
| Dated fold calendar (Appendix Table A1) | `revision/outputs/tables/TA1_fold_calendar.csv` (run `revision/A9_fold_calendar/fold_calendar.py`) |

## Scope of this repository

The results reproduced here are those of the **selected** configuration, which is the model the
paper reports and interprets: M3_Full / BGE-M3 / PCA(32) / L1 logistic regression, chosen on
inner-fold macro-F1 before any out-of-sample week was seen.

The wider configuration landscape discussed in the paper (six text encoders x three
dimensionality reducers x four classifiers for the two text-bearing feature sets, plus the four
classifiers for each of the two feature sets without text: 152 configurations in total) was
produced with the same panel and the same fold construction, substituting the reducer and
classifier. The selection protocol, the TPE budget and every parameter range are documented in
`SEARCH_SPACE.md`. Re-running that grid requires the additional packages listed in
`requirements.txt` and roughly a day of compute; it is not needed to verify any number the paper
reports and interprets.
